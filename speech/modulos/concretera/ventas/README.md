## Resumen
Punto de venta de concreto con metadatos específicos de producto.

## Funcionalidades
- Carrito, cobro y emisión de comprobante.
- Metadatos de venta de concreto: `edad` (28/14/7/3 días de curado), `rev` (resistencia kg/cm²), `descarga` (Directo/Bomba).
- Métodos de pago y crédito (integra wallet/crédito de concretera).
